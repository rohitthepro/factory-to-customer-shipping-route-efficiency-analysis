# Factory-to-Customer Shipping Route Efficiency Analysis

## 📌 Project Overview
This project is a data analytics dashboard built to analyze shipping routes for Nassau Candy Distributor. The goal of this analysis is to identify logistical bottlenecks and optimize transit efficiency from the factory directly to the customer.

## 🚀 Live Dashboard
Check out the live web app here: https://factory-to-customer-shipping-route-efficiency-analysis-5mhz8uh.streamlit.app/

## 🛠️ Tools & Technologies Used
* **Python** (Data processing and logic)
* **Streamlit** (Interactive web application framework)
* **Pandas** (Data cleaning and manipulation)
* **Plotly** (Interactive data visualizations)

## 📊 Key Features & Insights
* **Route Analysis:** Visualizes the most and least efficient shipping paths.
* **Bottleneck Identification:** Highlights delays in the supply chain process.
* **Interactive Filtering:** Allows users to drill down into specific transit times and locations.

## 💻 How to Run Locally
If you want to run this dashboard on your own machine, follow these steps:
1. Clone this repository.
2. Install the required libraries: `pip install -r requirements.txt`
3. Run the app: `streamlit run app.py` (replace `app.py` with your filename)
